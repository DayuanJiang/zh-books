# 原文核对

## 来源

- 文件：用户提供的 EPUB（`book.epub`），SHA-256 记在 `book.json` 的 `source` 里。EPUB 本身不放进仓库。
- 版本：书名页和版权页都是美国 Alfred A. Knopf 2018 年第一版《Bad Blood: Secrets and Lies in a Silicon Valley Startup》，电子书 ISBN 9781524731663（精装本 ISBN 9781524731656）。EPUB 3 由企鹅兰登书屋的制作流程生成，版权页上的转换代码是 v5.2_r1，文件最后修改于 2018 年 5 月 9 日。
- OPF 里有一个 calibre 书库编号，导航文件引用了 Kobo 阅读器的脚本，说明这个文件在 calibre 和 Kobo 里存放过。正文、注释和样式表都是出版社的原样，没有乱码。

## EPUB 的结构

- 阅读顺序：封面、书名页（一张图片）、版权页、目录、献辞、作者说明、序章、第 1 到 24 章、尾声、致谢、注释、作者简介，最后是出版社的推荐书目广告。全书没有分部。
- 每章开头有两个一级标题：先是写在两条竖线之间的大写章号（“| TWENTY-TWO |”），再是章名。
- 注释：书末共 372 条，按序章和 24 章分成 25 组。正文里没有注释编号。每条注释以正文里的几个词作引子（例如 “Elizabeth called me this morning”），引子链回正文里的一个空锚点，锚点放在被引用词句的开头。372 条注释和 372 个锚点一一对应，每组注释都只链回它标题所写的那一章。
- 场景分隔：93 处，每处是一条分隔线，后面跟一个只有破折号、对读者隐藏的段落。分隔后第一段的开头几个词用小型大写字母排印，EPUB 里存的是大写字母（“THE TERM “VAPORWARE” was coined”）。
- 引文：16 段，都用 `<blockquote>` 标记，内容是电子邮件、信件、Craigslist 广告和 Glassdoor 评论；第 22 章的那条评论里有一个两项的编号列表。
- 第 18 章富兹记在便笺上的 10 行要点、第 21 章信封上的 4 行地址，是 `<div>` 里一行一段的短句。
- 斜体用 `<i>` 标记，正文 181 处，注释 164 处。另有三处整段斜体由 CSS 设定：序章开头的日期行、献辞、第 22 章的意大利语章名。两处下划线：便笺上的 “ROLL OUT DISASTER” 和信封上的 “Via Hand Delivery”。一处下标：第 24 章维生素 B12 的 12。
- 图片只有封面、书名页图片和广告里的标志。正文里没有插图和表格。

## 导入和整理

```bash
uv run --project framework/tools python -I books/bad-blood/tools/prepare_epub.py book.epub prepared.epub
python3 scripts/site.py import-epub bad-blood prepared.epub --force
uv run --project framework/tools python -I books/bad-blood/tools/curate_source.py book.epub
uv run --project framework/tools python -I books/bad-blood/tools/check_source.py book.epub
```

`tools/prepare_epub.py` 先复制一份 EPUB，在副本上做四件事：

- 在每个注释锚点处放一个标记 `ZZNOTE<k>ZZ`（k 是这条注释在注释文件里的顺序），导入后还能知道注释在正文里的位置。
- 小型大写字母的开头词改回正常的大小写，人名、地名、月份和代词 I 保留首字母大写，例如 “Elizabeth’s early years were spent”。93 处逐一看过。作者简介里的 “JOHN CARREYROU” 改成 John Carreyrou。
- B<sub>12</sub> 改成 B₁₂，否则导入后会变成 B12。
- 便笺上的 10 行改成一个列表；信封上的 4 行地址改成一段，行与行之间换行。

`tools/curate_source.py` 再处理导入结果：

| 问题 | 处理 |
| --- | --- |
| 封面、书名页、版权页、注释、出版社广告被导成了章节（目录页和导航文件在导入时已经跳过） | 删除。EPUB 的封面图改作书架封面 `assets/images/cover.jpg` |
| 372 条书末注释在一个单独的注释文件里 | 每条注释改成所在章节的脚注 `[^n]`，放在注释引用的那几个词后面。注释保留引子，写成粗体（书里的引子是链回正文的链接），例如 `[^1]: **“Elizabeth called me this morning”:** Email with…` |
| 5 个锚点放在引子的第一两个词之后：第 11、15 章首段首字下沉的 The、She 之后，第 10、16、22 章场景分隔后的小型大写开头词之后 | 脚注同样放在整个引子之后。其余 367 条的引子都紧接在锚点后面，372 条全部按引子找到了位置 |
| 每章有两个一级标题 | 合成一个，编号章节写成 “# 1. A Purposeful Life”，`book.json` 里写 `number` |
| 第 22 章章名 La Mattanza 在书里是斜体 | 标题里不加斜体：阅读器把章名当纯文本显示，星号会露出来 |
| 场景分隔是分隔线加一个隐藏的破折号段落 | 只留分隔线 |
| 注释的网址里有 4 个零宽空格（排版用的断行提示），正文里有 7 个不换行空格 | 删掉零宽空格，不换行空格改成普通空格。两个细空格（单引号和双引号之间）照原样保留 |
| 两处下划线 | Markdown 没有下划线，改成普通文字 |
| 序章日期行和献辞的整段斜体，属于版式 | 改成普通文字 |
| 献辞没有标题 | 用目录里的 “Dedication” 作标题 |
| 导入时 `book.json` 的 `source` 记的是副本 `prepared.epub` | 改记原始 EPUB 的文件名和 SHA-256 |

各节的 id 是 dedication、authors-note、prologue、ch01 到 ch24、epilogue、acknowledgments、about-the-author，文件名沿用导入时的名字。

## 完整性核对

`tools/check_source.py` 逐节对照 EPUB 里对应的 XHTML 文件：

- 方法：EPUB 一侧取每个 `<p>` 的文字，不算标题和注释；en/ 一侧取每个段落、列表项和引文里的段落，不算标题和脚注定义，去掉 `[^n]` 和 Markdown 符号。逐段比较时只比字母和数字，不分大小写，所以开头词改了大小写、B₁₂ 写成下标、列表前面的符号这几处整理不算差异。信封地址在 en/ 里是一段，按换行拆回 4 段再比；编号列表的项号在 EPUB 里是正文文字，比较时加回去。词数按空格切分来数。
- 正文：30 节逐段一致，没有缺段，也没有重复的段落。逐节词数完全相同，共 101,309 个词，见下表，所以没有需要解释的差异。
- 注释：EPUB 有 372 条，en/ 有 372 条脚注。逐条比较文字，每条只出现一次，并且都在它链回的那一章里；正文里的 `[^n]` 和定义一一对应、顺序一致。注释共 8,176 个词，两边相同。正文里没有剩下的标记，也没有指向 EPUB 文件的链接。
- 斜体：正文 181 处、注释 164 处，两边相同（不算上面说的三处整段斜体）。
- 另外确认了：EPUB 的正文文件里，`<p>`、`<h1>` 和场景分隔的破折号之外没有别的文字；30 个标题逐一和目录对过；`site.py status` 列出 1,329 个要翻译的块（30 个标题、1,282 个段落、16 段引文、1 个列表），另有 93 条分隔线。

## 原文疑点和给译者的提示

整理中没有发现乱码、漏字或拼写错误。翻译时发现的原文疑点，记到各章的审校记录里。

- 作者说明第二段说，法律文件的出处写在书末的注释里（“in the notes section at the end of the narrative”）。这里的注释已经改成各章的脚注，翻译时可以照原文译，再加一条译者注说明。
- 尾声写于 2018 年初（“As of this writing”），当时霍姆斯和巴尔瓦尼还没有被起诉。两人后来在 2018 年 6 月被起诉，2022 年先后被定罪。是否加译者注，在翻译尾声时决定。
- 第 17 章一条注释里的 YouTube 链接，原文已经标了 “[inactive]”。
- 引文和注释里的 [*sic*] 是作者原有的标记，便笺上的速记（“K results all over map”）和邮件里的拼写错误照原样保留。
- 5 个锚点放在引子中间，是电子书制作上的小问题，不影响内容。
