# 术语统计

术语表 `glossary.md` 分两批定下来，这里是第二批依据的统计数据。

## 第一批（导入时）

- **候选词**：用 `en-zh-translation-polish` 的 `terms.py`（spaCy，`en_core_web_sm`）在导入的英文上抽取，频次不少于 8，得到 1813 个候选词。
- **核心概念**：预先列出 87 个，逐个统计出现次数和分布的章数。
- **结果**：77 条，加上审校中补的 gossip 和 label，以及第 1 章译者建议的 12 条常用词。
- **限制**：当时的英文还有乱码，候选数据没有保存。

## 第二批（用干净原文补做）

原文来自用户提供的 AZW3 文件，按章转成 Markdown 后统计，不含书末注释。

| 文件 | 内容 | 数量 |
| --- | --- | --- |
| `candidates.tsv` | spaCy 名词短语候选，频次不少于 3，含出现的章数，以及是否已在术语表里 | 3257（多词 999） |
| `index-terms.tsv` | 纸质版索引里的概念词条，含出现次数、章数、首次出现的章节，以及是否已在术语表里 | 600 |
| `people.tsv` | 纸质版索引里的人名，用来统一人名译法 | 177 |
| `definitions.tsv` | 原文里的定义句（we call、known as、labeled、the term 等） | 51 |

- **筛选**：从这几份数据里挑出书中特有、反复出现或作者专门定义过的概念。日常词不收，比如 time、value，它们在索引里是因为有特定的子条目。
- **结果**：59 条，写在术语表的“第二批”一节里，状态都是“初定”。
- **注意**：统计是按英文词形的正则匹配做的。索引词条的出现次数可能把同词根的普通用法也算进去了，要结合上下文判断。

## 一致性检查（全书译完后）

对每个术语，找出含这个英文词的段落，统计对应的中文段落里用了哪些译法。同一术语有不止一种译法的，回到上下文判断是否需要统一。
