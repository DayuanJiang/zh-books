# 原文核对

## 来源

- 文件：用户提供的 EPUB（`ThinkingFastandSlow.epub`），Farrar, Straus and Giroux 2011 年英文版，SHA-256 记在 `book.json` 的 `source` 里。EPUB 本身不放进仓库。
- 这个 EPUB 是从 Kindle 格式转出来的，共 72 个 HTML 文件，章节标题是加粗的普通段落，目录链接指向上一个文件的末尾附近，星号脚注放在书末的单独文件里。

## 导入和整理

```bash
python3 scripts/site.py import-epub thinking-fast-and-slow book.epub --force
uv run --project framework/tools python books/thinking-fast-and-slow/tools/curate_source.py
```

导入工具负责拆分章节、按目录给标题编号、复制图片。`tools/curate_source.py` 处理这本书特有的问题：

| 问题 | 处理 |
| --- | --- |
| 封面、书名页图片、五个部分的标题页（各两页）、“Also by Daniel Kahneman”、版权页、纸质版索引被导成了章节 | 删除。封面图改作书架封面。索引的页码对电子版无效，原书说明也建议用搜索 |
| 献辞没有标题 | 单独成节，标题写作 “In Memory of Amos Tversky” |
| 第 5 章荷叶题后的答案脚注、第 9 章“系统 1 的特征”列表中五项共用的脚注，放在书末的单独文件里，正文的星号链接指向错误的位置 | 正文里星号的位置保留，改成标准脚注 `[^1]`，注释文字从对应文件取来 |
| 两篇附录标题后的出处说明也在单独文件里，链接错位一个文件 | 作为斜体段落放在作者署名之后 |
| 附录 A 的 25 条参考文献是单独一个文件 | 改成附录 A 的脚注 `[^1]` 到 `[^25]`，正文里的编号引用一一对应 |
| 附录作者署名被识别成二级标题 | 改回斜体段落 |
| 各章之间的交叉引用链接指向 EPUB 内部文件 | 保留链接文字，去掉链接 |
| 缩进的段落被转换成两层引用 | 改成一层引用 |
| 26 张图片之外的图片没有被正文引用 | 删除 |

## 完整性核对

逐节比较英文词数和 EPUB 对应文件的词数：

| 章节 | 差异 | 原因 |
| --- | --- | --- |
| 引言、结论、第 38 章等 41 节 | 0 到 1 个词 | 图片说明一类的零星词 |
| 第 9 章 | 多 6 个词 | 挪进来的脚注 |
| 附录 A | 多 357 个词 | 并入的参考文献（303 个词）和出处说明 |
| 附录 B | 多 39 个词 | 出处说明 |
| 书末注释 | 少 23 个词 | 去掉的交叉引用链接目标 |

全书 183,511 个英文词，EPUB 去掉目录页、索引、版权页和著作列表后为 183,624 个词。没有发现漏段或重复。

## 已知限制

- 五个部分的标题（Two Systems、Heuristics and Biases、Overconfidence、Choices、Two Selves）没有保留成单独的页面；阅读器的侧边栏目前只有一层章节列表。
- 插图是原书的图片，图里的英文没有翻译，图题在正文里翻译。
- 书末注释按页码和引文对应，正文里没有标记，作为单独一节保留。
