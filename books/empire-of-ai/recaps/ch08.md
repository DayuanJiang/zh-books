在高管们看来，GPT-3 已经证明了规模定律。Anthropic 团队离开后，内部对商业化的抵制减弱，留下来的领导层在 2021 年初制定了研究路线图：用微软配有 1.8 万块 A100 的新超级计算机，把 GPT-3 再扩大到原来的 10 倍，把算力效率提高到 25 倍，并把语言和代码模型做成产品，从用户那里收集数据。

产品化带来新问题：审核 API 申请的规则“基本上全凭感觉”；过滤器误拦大量无害内容，后被改成可选。布罗克曼把 API 给了他兄弟所在的 Latitude，几个月后，一些用户用它的游戏生成儿童性虐待内容。代码生成团队进展最快，微软高管让 GitHub 把公开代码库里的全部代码交给 OpenAI。微软 2021 年 6 月先发布 GitHub Copilot，OpenAI 8 月才在 API 里发布 Codex，品牌知名度全归了 GitHub 和微软。同一年，奥特曼的个人投资似乎转向押少数大注，5 月又推出了 1 亿美元的 OpenAI 创业基金。

- 路线图承认算力已接近极限，单靠扩大规模比不上从 GPT-2 到 GPT-3 的飞跃，额外的进步必须来自更好的方法。
- 路线图指望产品化后的用户互动形成数据飞轮，大幅提升能力。
- 海迪·赫拉夫认为，OpenAI 的红队测试零碎随意，给不出安全保证。
- 依靠微软发布产品，OpenAI 正在失去用户数据，最重要的是对自身愿景的掌控。
- 奥特曼常说自己没拿 OpenAI 股权，但他在 YC 持有大量股份，YC 投给 OpenAI 的 1000 万美元最多可换来 10 亿美元回报。
