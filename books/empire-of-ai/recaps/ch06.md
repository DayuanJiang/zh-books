山姆·奥特曼 2019 年 3 月全职转到 OpenAI，带来了在 YC 用过的激进思路：信奉 10 倍法则，要 OpenAI 成为独一无二的那一家。他在年底的备忘录里要求公司到 2020 年底在技术成果、算力、资金和准备工作上做到第一，让微软满意，并降低透明度。

裂痕却越来越深。达里奥·阿莫迪的团队用一万块 GPU 训练出 1750 亿个参数的 GPT-3，米拉·穆拉蒂的应用部门要通过 API 发布，安全派力主尽可能推迟。内部传言谷歌快要发布大语言模型，安全派这才让步，API 在 2020 年 6 月发布，那个谷歌模型却始终没有现身。GPT-3 API 取得成功，安全派落败：奥特曼开始和微软谈判再获 20 亿美元投资，9 月，微软宣布将获得 GPT-3 的独家授权。2020 年底，阿莫迪兄妹等人离开，第二年 5 月宣布成立 Anthropic。

- 奥特曼以美国的对手可能抢先为由，要公司尽快推进、越来越不开放，安保也层层加码。
- 他指出公司里有探索研究派、安全派和创业派，呼吁三派团结。
- 作者认为，通过 API 发布 GPT-3 出自对竞争的过度担忧，OpenAI 此后还会这样做。
- 阿莫迪阵营发现奥特曼对微软的承诺和他们所知不符，开始怀疑他是否诚实；达里奥等人还向董事反映，他在微软交易和 GPT-3 部署上早已拍板，却操纵持异议的人，让他们以为自己有发言权。
- 作者指出，“分家”也关乎权力，Anthropic 后来和 OpenAI 只在风格上有所不同。
