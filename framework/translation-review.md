# 译文审校规范

审校只看一个标准：**在符合原意的前提下，让中文读者容易读懂。** 两项要同时做到。意思对但读不顺，或者读得顺但意思走样，都算没做好。

这份规范把下面几类资料整理到了一起：翻译质量评估的通行做法（MQM 错误分类、ISO 17100、GB/T 19682），中文写作和出版的规范（叶子南、余光中对英式中文的讨论，GB/T 15834、GB/T 15835），以及近两年研究大模型翻译和大模型评审的论文。出处列在文末。

## 一、几道工序

1. **译者自检**：对照原文查漏译、增译和意思是否走样，再修中文。
2. **独立双语审校**：由译者以外的人对照原文，把全文从头审一遍，改过的句子和没改的句子都要审。ISO 17100 把这一步定为必做，定义是“对照原文检查译文，看是否适合约定的用途”。
3. **中文连续通读**：只读中文，按章从头读到尾，检查前后是否连贯、指代是否清楚、用词有没有重复、概念有没有跳跃。读到疑点，再回去查原文。
4. **排版校样**：在阅读器里看真实页面，检查标题、脚注、图表、斜体和链接。

每道工序先列出问题清单，每条问题核实以后才改。改完再对照原文核对一次。

## 二、问题怎么记

每条问题记下：位置、英文原句、现在的译文、类别、轻重、说明、建议译文。

**类别**（参照 MQM 的七个维度和 GB/T 19682 的差错分类，按中文图书的情况合并）：

| 类别 | 包括 |
| --- | --- |
| 准确 | 误译；漏译；增译（加了原文没有的意思、解释或引语）；程度和语气变了（情态、限定、否定、比较基准、因果方向）；指代弄错 |
| 术语 | 不符合本书术语表；同一个概念前后译法不一致 |
| 中文表达 | 病句、搭配不当、语序不当、错别字、标点用错 |
| 风格 | 翻译腔；生硬的书面词；语气和作者不符；啰嗦、重复 |
| 体例 | 数字、单位、人名、书名、引号和括号的写法（GB/T 15834、GB/T 15835） |
| 标记 | Markdown 标记、脚注标记、斜体位置、段落对应 |

**轻重**（参照 MQM 的严重程度分级）：

- **严重**：改变了原文的意思，或者读者会读错、读不懂。
- **一般**：意思没错，但读着别扭、明显像翻译，或者术语前后不一致。
- **轻微**：读者基本不会注意到的小问题。

先改严重的问题。轻微的问题，改动有风险时可以不改。

## 三、翻译腔的常见表现

完整的诊断清单和改法见翻译技能的 `reference/translationese-symptoms.md` 和 `reference/techniques.md`（整理自叶子南《高级英汉翻译理论与实践》）。最常见的几种：

- 照搬英文的从句结构和语序，例如“一个场合，读者在那里……”；状语放在句末。
- 名词前堆了一长串定语，“的”字连用。
- 抽象名词作主语，例如“他收入的减少改变了他的生活方式”，可以改成“他收入减少，生活方式也变了”。
- “作出”“进行”“加以”这类虚化动词，例如“作出了热烈的反应”，可以改成“反应热烈”。
- 被动句用得太多；“关于”“对于”“当……的时候”“在……方面”这类介词结构太多。
- “一个”“一种”“们”“性”用得太多；他、她、它、他们这类代词用得太多；语义重复。
- 英文习语和固定说法照字面译。

这些只是线索，不一定都要改。连接词、被动句和抽象主语本身都不算错，要看放在句子里读着顺不顺。

## 四、改写时最容易出的错

研究发现，文学翻译里的流畅和忠实常常此消彼长；用大模型润色译文，提高的主要是流畅度、风格和术语，意思上的错误改得很少，而且会把译文改成润色者自己的写法。大模型翻译最常见的幻觉之一，是添加原文没有的内容。所以每处改写都要防这几类错：

- **加了原文没有的意思**：补出原文没有的主语、原因、限定或解释，或者编出原文没有的引语。
- **窄化或泛化**：例如把 benefit（受益）写成“用上”，把 born prepared（生来有这种倾向）写成“天生就会”。
- **语气变了**：推测变成断言（may 写成“会”），动机变成必然结果，或者删掉了 often、some、only 这类限定。
- **指代变了**：改换代词或主语以后，句子说的变成了另一件事。
- **作者的声音没了**：句子改得更华丽、更书面，堆砌四字成语，不像原作者平实的口吻。

改写的做法：

1. 先把原文的意思逐项核清楚（命题、主语、情态、限定、否定、比较、数字、因果、语气），再动手改中文。
2. 改完以后，像普通读者那样把整句连同前后文读一遍，确认读得懂、读着顺。
3. 读起来已经顺、意思也对的句子，就不改。

## 五、用模型审校时

- 先让模型逐条找出问题，并标上类别和轻重，再下结论。研究表明，这样做的判断比直接打分更接近人工评审（EAPrompt、GEMBA-MQM）。
- 请两个不同的模型分别独立审全文，再逐条核实它们找出的问题。模型提的意见不一定对，核实时要对照原文自己判断。
- 模型之间互相审校，代替不了专业的人工审校。重要的书请人抽查一部分，用来校准尺度：哪些算问题，改到什么程度合适。
